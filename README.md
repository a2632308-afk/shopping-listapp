# 🛒 쇼핑 리스트

의존성 없는 단일 파일 쇼핑 리스트 웹 앱. 빌드도, 서버도, 인터넷 연결도 필요 없습니다.

## 실행

[`index.html`](index.html)을 브라우저로 열기만 하면 됩니다. 더블클릭해도 되고, 저장소를 받은 뒤 아래처럼 열어도 됩니다.

```bash
git clone https://github.com/a2632308-afk/shopping-listapp.git
cd shopping-listapp
start index.html      # Windows
open index.html       # macOS
```

## 기능

- **추가** — 입력창에 타이핑 후 Enter 또는 "추가" 버튼. 입력 후에도 포커스가 유지되어 연속 입력이 편합니다.
- **체크** — 체크박스나 항목 이름 아무 곳이나 클릭하면 토글됩니다. 완료 항목은 회색 취소선으로 표시됩니다.
- **삭제** — 각 항목 우측의 `×` 버튼.
- **완료 항목 비우기** — 체크된 항목이 있을 때만 하단에 나타나며, 완료된 항목만 한 번에 제거합니다.
- **요약** — 헤더에 `전체 / 담음 / 남음` 개수가 실시간 표시됩니다.
- **다크 모드** — OS 설정을 따라 자동 전환됩니다.
- **반응형** — 모바일 화면에서도 정상 동작합니다.

## 저장 방식

항목은 브라우저의 `localStorage`(키: `shopping-list.items`)에 자동 저장되어, 브라우저를 닫았다 열어도 목록이 유지됩니다.

`localStorage`는 브라우저별·기기별로 분리되어 있으므로 **다른 브라우저나 다른 기기와는 목록이 공유되지 않습니다.** 브라우저 데이터를 삭제하면 목록도 함께 사라집니다.

## 테스트

실제 Chrome을 자동 조작하는 Selenium 기능 테스트로 32개 항목을 검증했으며 전부 통과했습니다.

| 영역 | 검증 내용 |
|---|---|
| 초기 상태 | 빈 목록, 안내문, 요약 문구, 버튼 숨김 |
| 추가 | Enter·버튼 양쪽 동작, 순서 유지, 요약 갱신, 입력창 초기화 |
| 빈 입력 방어 | 빈 값·공백만 입력 시 미추가, 앞뒤 공백 제거 |
| 체크 | 체크박스 클릭, 이름 클릭, 재클릭 해제, 취소선 적용 |
| 삭제 | 지정 항목만 삭제, 나머지 체크 상태 보존 |
| 완료 비우기 | 체크된 항목만 제거, 이후 버튼 자동 숨김 |
| 저장 유지 | 새로고침 후 목록·체크 상태 복원 |
| 손상 데이터 방어 | 깨진 JSON, 형식 어긋난 항목 처리 |
| HTML 주입 방어 | 태그 입력 시 텍스트로만 표시 |

사용자 입력은 `textContent`로 렌더링되므로 태그를 입력해도 문자 그대로 표시되고 DOM 요소가 생성되지 않습니다.

## 브라우저 지원

Chrome, Edge, Firefox, Safari 최신 버전에서 동작합니다. 다크 모드 테마에 `color-mix()`를 사용하므로 2023년 이전 브라우저에서는 일부 색상이 다르게 보일 수 있습니다.
